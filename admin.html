포트폴리오 관리

박치헌님의 GitHub 저장소와 연결하면 영상 링크를 직접 추가하고 정리할 수 있습니다. 입력한 권한 키는 현재 브라우저 탭에만 보관되며 다른 곳으로 전송되지 않습니다.

처음 한 번만 저장소 전용 권한 키를 만들어 사용하면 됩니다.

권한 키 만드는 방법
  1. 권한이 미리 설정된 GitHub 권한 키 만들기를 엽니다.
  2. Resource owner가 pcheon9696인지 확인합니다.
  3. Repository access에서 Only select repositories를 선택하고 pcheon9696.github.io만 지정합니다.
  4. Repository permissions의 Contents가 Read and write인지 확인합니다.
  5. Generate token을 누른 뒤 생성된 키를 위 입력란에 붙여 넣습니다.
